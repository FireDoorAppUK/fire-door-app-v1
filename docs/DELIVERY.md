# Criterii de livrare

O sarcină este gata pentru acceptare când:

- [ ] Criteriile din Issue sunt îndeplinite sau excepțiile sunt explicate.
- [ ] Modificările sunt într-un Pull Request legat de sarcină.
- [ ] Testele relevante au fost executate; comenzile și rezultatele sunt menționate.
- [ ] Există pași de verificare reproductibili și demonstrație pentru schimbările vizibile.
- [ ] Configurarea și documentația sunt actualizate.
- [ ] Nu sunt incluse secrete sau date reale în exemple.
- [ ] Riscurile, limitările și revenirea sunt descrise când este cazul.
- [ ] Observațiile de review sunt rezolvate și aprobarea obligatorie este prezentă.
- [ ] Proprietarul a acceptat rezultatul.

## Înaintea primei publicări

Confirmați găzduirea, costurile, accesul, configurarea secretelor, testele funcționale și monitorizarea erorilor. Dacă aplicația păstrează date, validați backup-ul și restaurarea înainte de utilizarea reală. Publicarea necesită o decizie explicită a proprietarului.

## Predarea proiectului

Documentați instalarea dintr-o copie curată, variabilele necesare fără valorile secrete, comenzile de test/build, serviciile externe, proprietarii conturilor, publicarea și revenirea la versiunea precedentă. Conturile de servicii ale proiectului trebuie să rămână sub controlul proprietarului.
