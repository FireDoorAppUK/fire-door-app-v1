## Starea proiectului

Repository-ul este în etapa de organizare. Nu conține încă aplicația, instrucțiuni de rulare validate sau un mediu de test publicat. Tehnologiile și funcționalitățile primei versiuni urmează să fie confirmate.

Regula Protect main a fost verificată la 29 septembrie 2026: activă pentru ramura implicită, Pull Request cu o aprobare, anularea aprobărilor după modificări, discuții rezolvate, ștergere și force-push blocate, fără bypass.

## Urmărirea lucrului

- [Sarcini deschise](https://github.com/FireDoorAppUK/fire-door-app-v1/issues)
- [Modificări în lucru și de verificat](https://github.com/FireDoorAppUK/fire-door-app-v1/pulls)
- [Verificări automate, după configurare](https://github.com/FireDoorAppUK/fire-door-app-v1/actions)

Fiecare sarcină trebuie să aibă un rezultat verificabil. Un Draft Pull Request arată lucrul în curs; un Pull Request pregătit pentru review arată o livrare propusă. Închiderea unei sarcini înseamnă că rezultatul a fost acceptat.
